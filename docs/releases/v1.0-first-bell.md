# CampusOS v1.0 "First Bell"

**Released:** 26 November 2026
**Demo:** Monday 30 November 2026
**Try it:** https://campusos-sudo.vercel.app
**Built by:** Sudo Squad (GDG ITB, Case 1)

This is the first public version of CampusOS. It's a phone app for Computer Engineering students at USK that brings together three things:
- your class schedule;
- your assignments;
- verified class changes from class reps.

It works in English and Indonesian.

**For teammates:** please go through each section and tick the boxes you've checked yourself on your own phone. Leave a comment next to anything that's wrong, missing, or confusing. When everyone has confirmed, we'll use the last section to plan the next release.

## 1. Getting started

- [ ] **Landing page.** Visitors who aren't signed in see a short intro to CampusOS with a "Sign in with Google" button. The page can be read in English or Indonesian.
- [ ] **Sign in with Google.** Students use their own Google account. There are no passwords to remember.
- [ ] **Three-step setup** after the first sign-in:
  1. Choose a language (English or Bahasa Indonesia).
  2. Pick your classes. You can search by course code or name, and when a course has several sections, choose your *Kelas*.
  3. Turn on reminders. The app shows a sample notification first, so you know what you're agreeing to.
- [ ] **Fill from KRS (new).** In step 2, students can copy their KRS from SIAKAD and paste it in. CampusOS then ticks their classes automatically.
  - It also lists any courses it couldn't match.
  - Students still check the ticks before saving.
  - The pasted KRS stays on the phone. It is never sent anywhere or saved.
- [ ] **Change classes later** from the Account menu.

## 2. Today

- [ ] **Today's timeline.** Today shows the day's classes in order, each with its time, room, lecturer and length, plus your free time between classes.
- [ ] **Now / Next markers** show which class is happening now and which one is coming up.
- [ ] **Changes show up on the timeline.** A cancelled class (lecturer absent) is marked as cancelled. A moved class shows the new room highlighted, with the old room crossed out.
- [ ] **Upcoming deadlines** appear on Today.
- [ ] **Campus time.** All times are in WIB (Banda Aceh time), whatever time zone the phone is set to.

## 3. Assignments

- [ ] **One format for every assignment.** Each assignment has a title, its class, instructions, links (Google Drive, e-learning, etc.) and a due date and time.
- [ ] **Grouped by deadline:** overdue, today, this week, later. Each shows how much time is left, e.g. "3 d left".
- [ ] **Class reps can add assignments** for their own classes. The form reads the due date back in words (e.g. "Mon 7 Dec, 23:59 WIB") so mistakes are caught before posting.
- [ ] **Class reps can delete an assignment** they posted by mistake. The app asks for confirmation first.
- [ ] **Students can only read.** They can't change or delete anything.

## 4. Class updates (lecturer absent / room change)

- [ ] **Report a change.** A class rep can report that a lecturer is absent or a room has changed, with a short note, in a few taps.
- [ ] **Only verified people can post.** The "Report a change" button only appears for that class's verified rep, and the app checks this again when the update is sent. Ordinary students can't post.
- [ ] **Updates tab.** All recent changes for your classes are listed, with who posted them and their role (e.g. "verified class rep").
- [ ] **Today updates as well**, as described in section 2.

## 5. Notifications

All alerts arrive as phone notifications. CampusOS does **not** send emails.

- [ ] **Class reminder** 30 minutes before each class.
- [ ] **Deadline reminders** 24 hours and 1 hour before an assignment is due.
- [ ] **Change alert** when a class rep posts an absence or room change. It arrives within about 5–10 minutes.
- [ ] **Tapping a notification** opens the right screen in the app.
- [ ] **Reminder status** is shown in the Account menu, where you can turn reminders on.

## 6. Install on your phone

- [ ] **Android:** in Chrome, tap the menu, then "Install CampusOS". It opens full-screen like a normal app.
- [ ] **iPhone:** in Safari, tap Share, then "Add to Home Screen". The app shows iPhone users how to do this, because iPhones only allow notifications once the app is on the Home Screen.
- [ ] **No connection:** when there's no internet, the app says so clearly instead of showing a broken page.

## 7. Language and screen sizes

- [ ] **Every screen** is available in English and Bahasa Indonesia, and you can switch at any time from the Account menu.

## Not in this version (left out on purpose)

These were cut to finish on time. They're good candidates for the next release.

- Editing an assignment after posting. For now, delete it and post it again.
- Marking an assignment as done.
- Reporting a **rescheduled** class (new day or time). Only "lecturer absent" and "room changed" are supported.
- A full week view of the timetable on laptops.
- Using the app fully offline.
- Uploading assignment files. Assignments use links instead.

## Known limits

- When two classes overlap, the "Now" marker shows only one of them.
- Change alerts can take a few minutes to arrive, because the app checks for new alerts every 5 minutes.
- Fill from KRS only recognises course codes written like "STIK1005" (four letters and four digits, no space). This matches how SIAKAD writes them.
- Class reps have to be set up by the team after they sign in for the first time.
